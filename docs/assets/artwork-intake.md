# 原创插画接收与处理规范

## 本批次补充（2026-11-06）

用户已确认本批成品日历扫描可进行局部修复、重绘、构图调整与二次创作，保留统一水墨风格、完整人物及背景景物；不保留扫描纸面、打孔、旧文字或日期色条。该决定替代本批此前尚未获重绘授权时的限制，原件永不覆盖原则不变。扫描目录月份只作为来源／制作批次，最终套装不建立固定日期关系。

具体标准见[扫描清洗与内容制作方案](scan-cleanup-production-plan.md)，待执行步骤见[按月推进清单](scan-cleanup-monthly-checklist.md)。本轮仅归档，清单确认前不启动月度清洗。

## 1. 原则

- 原图扫描件是不可变母版。
- 所有清理、裁切、去底色、色彩校正和尺寸转换都输出新文件。
- 未经用户确认，不覆盖原件，不改变构图，不重绘人物和关键物件。
- 原件、候选处理图、批准成品和 App 优化资源必须可区分。

## 2. 每张插画的交付信息

- 稳定内容 ID、来源批次和原文件相对路径；
- 作者/设计师；
- 创作完成日期；
- 扫描日期与设备；
- 原稿尺寸；
- 扫描分辨率和色彩空间；
- 文件格式；
- 是否包含文字、日期或只包含插画；
- 可脱离日期与文字独立使用的插画层/插画母版；
- 商业授权范围；
- 备注和已知瑕疵。

扫描目录中的月份和原文件名仅用于来源追溯，不从图上提取日期作为最终内容字段，也不用于运行时固定映射。运行时日期、农历、星期和语录由 App 排版渲染。本批整页扫描经独立提取／重绘形成无字背景后，才满足动态排版需要；整页扫描本身不是可直接使用的最终资源。

## 3. 建议扫描规格

- 优先 TIFF 或无损 PNG；不把 JPEG 作为唯一母版。
- 建议至少 600 dpi，保留原始像素，不预先锐化或降噪。
- 优先嵌入明确的 ICC 色彩配置；无法确定时记录扫描软件的实际输出。
- 文件名不使用“最终版”“新版”等易混淆文字，使用日期、批次和版本号。

示例：

```text
MCP-001_artwork_scan_batch01_v001.tif
```

## 4. 建议处理层级

1. `source_scan`：原始扫描，永不覆盖。
2. `cleanup_candidate`：灰尘、纸张偏色和扫描瑕疵处理候选。
3. `approved_master`：经用户和设计师确认的数字母版。
4. `layout_derivative`：不同 Widget 构图的裁切或透明图层。
5. `app_asset`：按设备和 Asset Catalog 要求生成的优化资源。

本批目录、分层归档和 Git 边界按[制作方案](scan-cleanup-production-plan.md#8-目录与-git-边界)执行；原扫描与大尺寸母版保留在仓库外，优化资源在获准接入时单独导入。

## 5. 验收检查

- 原始扫描校验值可复核。
- 纸张、线条、色彩和人物细节没有被过度处理。
- 不同尺寸裁切不切断人物面部、手部和关键叙事物件。
- 浅色、深色、着色和透明 Widget 外观均有可读方案。
- 优化资源与批准母版可追溯。
- 设计师／用户确认视觉结果，项目负责人确认授权及背景与语录的配对关系；不核定固定展示日期。
