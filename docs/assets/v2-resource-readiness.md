# 高保真 v2 资源就绪审计

日期：2026-10-30。用户要求先检查、补齐实现素材，不急于业务开发。范围为公共 `docs/` 中的资源、导出工具和规范；`ios-client/`、`android-client/` 和工程配置不改。

## 结论

此前 **未准备好**：v2 保留了正确高保真和真实字体，但没有随定稿更新的独立素材；唯一旧铜环/纸纹等位于被否决的 v1，不能沿用为最终切图。

本次补齐 3 类位图候选、15 张倍率导出（铜环保留 V1/V2/V3 三版）、18 个矢量图标及其 PDF Asset Catalog、对照预览和统一资源登记。可以用于下一步局部材质/视觉核对，**不能称为全部正式资源齐备，也不据此直接启动全页面实现**。设计师插画尚未交付是既有依赖；本轮没有擅自替其生成年度插画。

阶段 2 更新：`DecorCandidates.xcassets` 与 `IconCandidates.xcassets` 已接入 iOS/macOS App targets，用于今日页内部还原和运行截图检查；Widget targets 未接入。候选状态、纹理限制及正式插画缺口均未改变，当前运行通过不等于设计师视觉批准。

## 素材准备规则

1. 只有原稿和真实字体已经确认；本轮补制装饰/图标为候选，技术可编译不等于视觉一致。
2. 母图、倍率导出、矢量源、预览和校验表分开保存；不覆盖原稿、v1 历史或字体。
3. 不把日期、语录、出处、价格、按钮文字、动态状态及翻页阴影预烘焙到图片。
4. 不用一张“整张卡片 + 纸纹 + 阴影”图片替代可适配的原生纸页，尤其年度册必须使用单页。
5. 两种纹理目前不保证无缝：预览有分块，当前只能局部填充/裁切，不能标记为无限平铺成品。
6. 阶段 2 只将候选接入 App targets 的今日页内部路径；未接入 Widget，不改变签名、部署版本、StoreKit 或正式资源状态。资源辅助脚本仍只用于导出/技术核验。
