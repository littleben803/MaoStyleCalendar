## 1. 目标与交付单位

从成品日历扫描中制作可跨年使用的内容套装。每套包含：**无字背景 JPG、独立语录、原稿分行／分列、版式坐标、配色、来源与版本记录**。

背景、语录和版式由稳定 `contentPackID` 绑定，作为一套内容整体使用。扫描原件目录中的 1～12 月只是来源与制作批次，不是产品内容分类，也不决定运行时展示日期。

- 不录入图上日号、月份、年份、星期、节气或农历作为内容包字段；旧日历信息从背景中去除。
- 可记录来源月份、原文件相对路径和校验值，作用仅为查找、审计和断点续作。
- 运行时由项目既定的年度分配器为完整内容套装分配日期，同年同版本映射稳定，新年重新分配。见[跨年份分配规则](../product/content-allocation.md)。
- 新制作或修订不修改稳定 ID，不在年中擅自重排正式池。制作中不改分配算法或正式默认数据源。

## 3. 插画清洗与重绘

原扫描只读，任何处理均生成新文件。用户已明确允许本批次局部修复、整体重绘、调整构图和二次创作，以统一水墨风格、完整自然的画面为目标，不要求逐像素复原。

1. 参考原稿人物、动作、景物和意境，判断提取、局部修复或重新创作哪种方式更合适。
2. 去除所有日期信息、语录、出处尾注、节日标签、签章及可辨识文字；书本等物件保留造型，书面文字不进入背景。
3. 不保留打孔、纸边、扫描阴影、透印、歪斜或扫描偏色；这些不是待还原的画面内容。
4. 以同一套细墨线、淡彩、水墨渗化、纸面融合和细节密度制作，不混入照片、漫画或厚涂风格。
5. 文字遮挡插画时，可以参考重复画面的无遮挡部分，也可以直接重绘；保留自然的人体、手、衣袖、书本及空间关系。
6. 留白通过自然构图取得。禁止为方便叠字而擦除、雾化或大面积淡化人物胸腹、衣纹、手臂与景物。

特殊类型按以下规则制作：

| 类型 | 规则 |
| --- | --- |
| 浅纸底 | 融合项目已确认纸面风格，保留水墨和淡彩边缘；扫描纸面不作为最终材质标准 |
| 通版红底 | 保留红纸与墨色的统一关系，人物和衣纹必须完整；日期与语录使用相应浅色配色 |
| 下部独立红／黑日期条 | 去除整块色条，依据原稿延展桌椅、衣物、景物或地面，避免矩形补丁、硬接缝或简单裁掉画面 |
| 文字密集压画 | 允许整体重绘或二次创作，不反复投入机械修补；先保证场景自然，再安排文字留白 |
| 跨月重复插画 | 可以参考或复用已确认插画，但每套语录与版式关系单独保留；不因画面相似就合并内容包 |

每张使用独立提示词，写明该图的主体、场景、构图、特殊处理和禁用元素；统一风格要求可共用，不用一条泛化提示词机械套满全年。使用内置 imagegen，每次一张；不自动切换 API/CLI、不新增模型或依赖。

## 4. 语录与出处分离

- 先对原稿做文字抄录，再制作无字背景。可用本地 OCR 辅助，横排与竖排均须对照扫描逐字校对。
- “—《毛选》”等尾注从展示语录中移除，保留为独立的来源标签。该标签不等于已核实篇名、卷次、版本和页码。
- 分开保存逻辑语录文本与展示分段：横排逐行、竖排逐列，并明确从右向左或其他实际阅读顺序。
- 保留原稿换行、分列、标点及行内分组；行内空隙属于版式，不混入逻辑文本。
- 缺字、疑似错字、打孔遮字和暂补字列入待核验清单，不静默改成“已核验原文”。04 号“定要将”、08 号暂补“为”继续跟踪。
- 不自动生成英文并称为权威译文。中文底本、英文对应、上下文与编辑审校依照[语录来源规则](../research/quote-source-policy.md)另行完成。

每月可以完成插画制作、抄录与版式验收，同时保留出处核验待办。只通过视觉验收的内容包仍保持 `candidate`；只有项目规定的全部内容与授权审核完成后才可进入 `approved` 与正式 Release。

## 5. 版式与动态日期

背景与文字使用同一坐标系：左上原点，横纵坐标各归一化为 0～1；当前画面基准比例为 2:3。

每套记录语录起点、逐行／逐列内容、字体角色、字号比例、行／列距、标点处理、文字区域、主体不可遮挡区域、日期位置模板和配色。依据原稿与新插画人工确定并逐图复核；不声称已实现自动避让。

| 元素 | 已确认规则 |
| --- | --- |
| 横排语录 | 保留原稿逐行和行内分组，按记录的起点与行距渲染 |
| 竖排语录 | 保留原稿分列与阅读顺序，按记录的列距渲染 |
| 日号 | 独立动态文字，沿用试制确认的日期字库及字号；不烘焙进 JPG |
| 月份 | 在原试制模板基准上增大 2pt，独立一行 |
| 年份与星期 | 合为一行并使用统一增大字号，沿用试制的实际实现 |
| 干支年农历 | 位于年份／星期下方，与该行同字号，示例为“丙午年 九月廿七” |
| 对齐 | 顶部日期信息三行右对齐；底部三行左对齐，紧凑模板与大日号留出间距 |

日期、星期、干支年与农历由实际运行时日期计算；农历支持闰月，干支年在农历春节切换。示例不写死到数据或背景中。当前真实字体角色见[字体角色清单](../design/handoff/v2/specs/font-roles.json)，不擅自换字体。

配色逐图保存纸面、日期、语录、辅助文字颜色；通版红底和混合底色分开判断，不使用整图平均颜色决定所有文字颜色。

## 6. 图片与压缩标准

| 交付类型 | 尺寸与体积规则 |
| --- | --- |
| 原扫描 | 保持原 PNG，不覆盖、不预压缩 |
| 制作母版 | 保留生成／修复的原生无损版本与版本号，不为凑尺寸虚假放大 |
| 常规 App 背景 | 当前以已实机确认的 1024×1536 为批量基准，保持 2:3，优先每张不超过 200,000 字节 |
| 背景尺寸上限 | 宽不超过 1440、长边不超过 2160，保持比例；有真实更高分辨率母版时再选用该档，目标 150～250 KB、上限 350 KB，须记录和验证，不能把现有小图放大冒充更清晰 |
| 壁纸输出 | 保存时按设备原生纵向比例合成，宽上限 1440、长边上限 3200；目标约 500 KB～1 MB，以真实导出检查为准 |

常规 JPG 使用明确 sRGB ICC、渐进式编码与优化编码。直接从无损母版导出，逐张在体积预算内选择可接受的最高质量；不反复重压 JPG，也不把不同编码器的质量数字当作同一尺度。对红纸色阶、墨线、脸、手、书本和纸纹做原生像素局部检查，同时查看实际卡片尺寸。

优先保持当前基准。个别画面在 200 KB 内明显损伤细节时，进入当月例外表，记录分辨率、质量、体积及对照，不擅自降到不可接受的质量或静默突破 350 KB。按 365 张全部不超过 200 KB 估算，背景合计不超过约 73 MB；这是图片文件预算，不是整个安装包大小承诺。

App 背景没有任何文字；卡片日期和语录由程序叠加。壁纸不显示日期，可导出原稿语录版或仅插画版；试制／未完成内容核验时保留已确认的试制标记。按宽度完整放入插画，再延展同色纸面适配长屏，避免拉伸人物或直接铺满裁切。壁纸像素尺寸不代表源插画具有同等原生分辨率。

## 7. 稳定 ID 与来源登记

全量制作开始前先建立 365 张源文件登记表，检查数量、可解码性、方向、哈希及重复风险；为每个有效来源固定一个内容 ID。

- 现有 `pack-0001`～`pack-0010` 保留不变，并与原文件校验值对应。
- 其余来源从 `pack-0011` 延续登记，登记后不因月份、文件名、制作顺序或修订而重新编号。
- ID 不包含年份、月份或日号语义。来源月份只作为登记表中的批次字段。
- 自然排序仅帮助首次登记可复现，不作为运行时内容分配规则；只有清理后的正式资源池才能按项目既定流程接入分配器。
- 修订沿用同一 ID，增加 `revision` 并记录当前有效文件及哈希，预览必须由当前有效成品生成。
- 发现重扫、错放、缺页或完全重复内容时先列异常，不擅自删除、补造或改变内容包数量。

最少记录：内容 ID、来源批次／相对路径／SHA-256、原生尺寸和方向、作者及授权待办、制作方式和提示词、版本、语录与分段、版式／配色、有效母版和 JPG 路径／哈希、导出参数、视觉／抄录／出处／授权审核状态。

制作、视觉验收、语录抄录、底本核验、授权和 Release 状态分别记录，不以“图片完成”代替“内容获准发布”。

## 9. 每月完整交付与验收

每月作为一个完整阶段，内部按图小步制作，不逐图反复要求用户批准。交付整月后汇报、等待确认，再进入下一个来源月份。

每月交付包含：整月无字背景、叠字预览、原稿对照、重点原生像素局部、无损母版与提示词归档、结构化语录／版式数据、体积与哈希清单、待核验及例外列表。已有试制图按有效版本复用，仍纳入月度整批风格与配对复核，不重复无意义重绘。

验收检查：

1. 数量及 ID 与源文件登记表一致；原 PNG 校验值不变。
2. 无文字、日期、打孔、扫描纸边或底部日期色条残留；没有大块擦除、身体断裂、错误手部或硬接缝。
3. 水墨、淡彩、纸面与人物处理在本月及已确认月份之间协调；关键物件和主体完整。
4. 语录与背景匹配、分行分列与阅读顺序正确，疑字／暂补字有记录。
5. 日期三行对齐、农历与颜色正确；使用不同运行时日期检查，不固定沿用原扫描日期。
6. JPG 尺寸、体积、ICC、解码及当前版本哈希通过；不以缩略总览代替原生细节检查。
7. 壁纸检查完整插画、长屏纸面延展、无日期及文字可读性。工程接入与真机检查只在获准的 Debug 范围执行，不把离线预览称为实机验收。
8. 报告明确完成项、修改／新增文件、未改区域、验证命令、构建情况、未解决事项及下一月建议。

月度制作验收允许单列出处／授权待核验事项；这些事项必须继续阻止正式发布。影响画面、配对或文字准确性的未解决问题不能在报告中隐藏或自动打勾。
