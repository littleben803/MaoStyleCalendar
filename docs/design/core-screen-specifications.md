# 年度册、设置、壁纸与付费墙设计规范

更新日期：2026-10-29

## 1. 全局导航

紧凑宽度底部四个主 Tab，顺序固定为：今日、年度册、壁纸、设置。iPad、iPhone Duo 展开态和 Mac 使用同样信息架构映射到 Sidebar，不机械放大 Tab Bar。

## 2. 年度册

- 标题只显示“年度册”，不显示“某年 · 365 幅原创手绘”副标题；
- 当前年份作为可操作信息显示，不进入产品品牌文案；
- 月份索引用于跳转当年月份；
- 切换年月后从月初加载 6 张卡片，滚动接近当前批次底部时再追加 6 张，直到该月最后一天；
- 每个日期显示一张独立纸页，不使用多层叠页视觉；
- 单张纸页展示动态日期、插画和适合缩略图阅读的语录片段；
- 日期复用今日卡片的字号比例、颜色和间距。日号下方依次显示月份与星期、干支与农历，日期区随插画构图定位；
- 点击单张纸页进入复用的卡片翻转详情。

## 3. 设置

设置是第四个一级入口。桌面小组件的日期、干支和农历、语录默认显示，可独立关闭；App Group 保存显示偏好。

设置首页与年度册、壁纸工坊共用居中标题和红色短线，解锁按钮与标题区的间距沿用壁纸工坊的首个控件间距。

2026-11-09 起，「主屏幕图标」仅在支持替换图标的 iOS Debug 构建中显示，归入设置的「调试」分组。

## 4. 壁纸工坊

### 页面结构

2026-10-29 修订：移除锁屏/主屏目标和语言选择，排版扩展为六种；“仅插画”作为明确的排版选项恢复。页面依次为标题、可滑动壁纸预览、整行排版选择器、高清导出按钮、主 Tab。

### 内容切换

- 中央预览卡片左右滑动，在 365 套 `DailyContentPack` 间切换；
- 插画和对应语录一起切换，不允许拆开随机；
- 预览卡片不显示日期、年份、星期或农历；
- 壁纸语录跟随系统首选语言：中文使用中文，其他尚未支持的语言回退英文；不提供手动语言控件；
- 英文显示经过批准的权威片段或项目编辑译文；仅插画模板不渲染语录。

### 六种编排模板

1. `留白竖排`：插画集中下部，中文语录竖排在侧边留白区；英文使用侧边窄栏横排，不逐字竖排。
2. `留白横排`：插画集中下部，语录在上方留白区横排，保持充足呼吸感。
3. `上文下画`：上部独立文字区、下部完整插画区，强调清晰的图文分区。
4. `上画下文`：上部完整插画、下部纸质文字区，适合上方构图较饱满的作品。
5. `左右对景`：插画与语录左右分区，窄屏控制文字栏宽度，宽屏可舒展。
6. `仅插画`：隐藏语录，仅导出插画，不添加日期。

模板只改变编排和文字可见性，不改变插画与语录配对。选择器独占整行，每项展示编排缩略图与名称；窄屏允许水平滚动，不把六个触控区域压缩至不可点击。切换内容保留所选排版。

### 导出

- 主按钮统一为“导出高清壁纸”；
- 默认按当前设备屏幕像素尺寸生成，不显示“按当前设备尺寸生成”提示；窗口尺寸不作为壁纸分辨率；
- 点击后打开系统分享表，系统可能提供“用作墙纸”、存储图像、AirDrop 或文件等操作；
- 删除独立的“使用系统分享”文案；
- 普通第三方 App 不能绕过系统直接设置 iOS 锁屏/主屏壁纸；
- 若未来增加“保存到照片”，需申请 `add-only` 照片权限并提供用途说明。

## 5. 付费墙

- 不出现具体年份；
- 标题与营销内容不出现 `365` 或“原创手绘”；
- 采用单一永久解锁产品，不默认设计周/月订阅；
- 推荐标题：“解锁完整日历”；
- 推荐副标题：“一次买断，永久使用全部内容与功能”；
- 已确认的桌面小组件权益为每日更新插画与自定义显示。各可用尺寸免费使用固定插画，当天日期和语录照常更新。完整规则见 [IAP 产品与解锁策略](../product/iap-strategy.md)；
- 价格必须来自 StoreKit 本地化产品信息，设计稿不写死币种和金额；
- 必须显示恢复购买、稍后再说、购买条款和隐私政策；
- 不使用倒计时、伪折扣、默认勾选或制造稀缺感。

### 购买区优先的视觉层级（2026-10-29 修订）

- 缩小装饰插画，取消占据半屏的大型叠页主视觉；保留纸感、朱红与项目字体气质。
- 首屏优先展示标题、一次买断说明和购买区。六行权益、恢复购买与法律链接位于购买区下方，按需滚动查看。
- 付费墙逐行展示 [六项已确认权益](../product/iap-strategy.md#3-永久解锁能力)。今日翻页越界时显示 `永久解锁，可翻阅所有卡片。`。年度册锁定入口显示 `永久解锁，可查看完整年度册。`。壁纸工坊锁定入口显示 `永久解锁，可查看所有壁纸、切换排版并高清导出。`。场景提示放在购买按钮上方。
- 购买区是视觉中心：清晰显示本地化价格、`一次付费 · 永久使用`，以及整行高对比朱红按钮 `永久解锁`；装饰不得与按钮争夺注意力。
- 价格与按钮紧邻；概念预览用“价格待定”占位，正式 UI 使用 StoreKit 本地化价格，不展示实现说明。
- 购买区在常规字号首屏可见；小屏和大字号下权益可滚动，底部购买区保持可达，避免遮挡正文。
- 恢复购买、关闭、条款与隐私保持可读和可操作，但视觉权重低于主按钮。
- 价格获取失败显示重试入口，不允许在价格未知时发起购买；购买处理中防止重复点击，取消后可继续浏览。
