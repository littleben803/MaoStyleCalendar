# 今日卡片正反面与手势规范

更新日期：2026-11-09

## 1. 正面

- 视觉主体为实体铜环装订的米白纸张日历。
- 左滑进入下一天，右滑返回上一天。
- 正面下方的四张叠页使用相邻日期的插画、语录和日期。向左拖动时按未来日期排列，向右拖动时按过去日期排列。
- 手机紧凑宽度下，卡片高度随可用空间延伸至接近 Tab Bar。插画等比铺满，日期与语录按加高后的版面定位。
- 日号下方第一行显示“月份.星期”，第二行显示干支与农历，两行均沿用日号颜色。同尺寸卡片的日期字号及日号与第一行的垂直间距一致，日期区的位置随插画排版调整。
- 插画延伸至卡片底部，整张卡片作为详情入口。
- 点击卡片正文或插画区域翻到背面。

## 2. 翻转

- 卡片使用可中断的 3D 翻转动画，建议基础时长约 0.55 秒，并根据手势/设备性能调节。
- 翻转前半程压暗正面并增强纸张侧边阴影；经过约 90° 时切换正反面内容；后半程轻微弹性落位。
- 翻转过程中避免同时触发换日。
- 开启“减少动态效果”时降级为正反面交叉淡入，不进行大幅 3D 旋转。

## 3. 背面结构

背面仍保持同一张纸页的材质和尺寸，周围 App 界面覆盖暖色半透明蒙层。

### 固定 Header

- 标题固定使用“语录详解”；
- 日期位于标题下方；
- 关闭按钮位于 Header 右上角，命中区域不小于 44×44 pt；
- Header 不参与正文滚动。

### 可滚动 Content

- Header 以下为独立正文滚动区；
- 正文依次呈现原文与出处、历史背景、当下解读，按条目显示已有内容；
- 内容高度未超过可用空间时保持静止，不制造空滚动；
- 内容超过可用空间时按系统自然滚动，不显示“继续阅读”或向下箭头提示；
- 正文滚动位置在关闭背面后可以重置；是否跨日期保留不作为 V1 要求。

## 4. 关闭与手势冲突

- 点击关闭按钮：翻回正面；
- 点击卡片外半透明蒙层：翻回正面；
- 背面正文内点击：不关闭；
- 背面打开时禁用左右换日手势；
- 正文纵向滚动优先于卡片关闭，不使用下拉关闭，避免与阅读冲突。

## 5. 无障碍

- VoiceOver 将正面卡片暴露为“查看本日语录详解”的组合入口；
- 翻到背面后将无障碍焦点移动到“语录详解”；
- 蒙层不应让屏幕阅读器访问到底层 Tab 和按钮；
- 关闭后恢复到触发翻转的元素。
