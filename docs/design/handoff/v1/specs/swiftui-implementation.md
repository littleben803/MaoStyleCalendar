# SwiftUI 还原说明

## 字体和文本

- 中文标题：SourceHanSerifSC-SemiBold；正文、竖排、元数据：SourceHanSerifSC-Regular；英文和独立日号：Literata。
- 中文日期中的数字保持所在中文字体，避免混排频繁切换字库。
- Literata 的文件 PostScript 名称包含 ExtraLight，但实际变量轴基准为 wght=400；不能仅凭名称选择字体实例。光学字号 opsz 跟随展示字号，并限制在字库支持区间内。
- 在 SwiftUI 中以语义字号/ScaledMetric 支持动态文字，不能把 PNG 上的像素值当字号。参考值在 design-tokens.json。
- 竖排使用真实竖排字形和标点，不逐字旋转拼接；读取顺序从右列到左列、列内从上到下。排版和 VoiceOver 分别验证。
- 文案由结构化数据绘制，不把日期、语录、按钮或来源切进位图。英文单独横排，长句根据审定短版降级，不能任意截断改变意思。

## 颜色和材质

- Theme.xcassets 提供动态浅/深基础颜色；以 sRGB 命名色接入 SwiftUI Color。
- 浅色纸纹叠在纸面上的参考 opacity=0.32，页面背景=0.14。它是整片低对比纹理，并未验证无缝平铺，不默认使用重复 tile 模式。
- 深色参考为暖墨底、暖白字和柔和朱红。设计师正式插画的深色处理仍待样本验证；此包没有暗改原画。
- Widget 着色稿的蓝色是系统外观示例，不是可选择主题。实际根据 widgetRenderingMode 分开处理背景、文字语义组和图片，不对整张截图统一滤镜。
- 普通日历卡片的圆角、纸边、分隔线和阴影使用 SwiftUI Shape/overlay/shadow 绘制，不需要固定尺寸的整卡背景切图。
- 铜环是独立透明贴图，仅用于 App 今日卡片；不强行给所有 Widget 增加铜环。卡片外沿所有装饰在 Widget 内部裁切。

## App 页面

### 今日与详情

- 今日参考容器 390×844 pt，卡片 x=20/y=91/w=350/h=637，卡片层叠仅今日使用；年度册使用单张纸页。
- 日期与语录在上部，下部插画；铜环图框 [182,70,26,63]。参考稿采用适应焦点的裁切，不拉伸人物比例。
- 插画铺满正面纸页，整卡可以点击。
- 左滑下一天，右滑上一天。点击卡片内容翻到背面，原拟真翻页/翻转要求保持不变。
- 背面 Header 固定为“语录详解”与日期；内容区包含出处、摘编说明、原文片段、历史背景、解读和翻译说明，整个正文区一起滚动。截图中的“排版说明”为测试内容，不能用于正式解读。
- 关闭图标视觉尺寸可小，但命中区域至少 44×44 pt；蒙层关闭与正文滚动不冲突。减少动态效果时交叉淡入。
- 阴影与叠页偏移是视觉参数，实际可用高度不足时应收敛装饰并保证阅读与操作；不把参考 y 坐标固定用于所有设备。

### 年度册

- 年份跟随系统年份，按日期生成当年页面；首图年份只是当前样例。
- 两列为紧凑宽度的基线，窄窗口与动态字号可改列数，不压缩至不可读。
- 卡片点击复用翻转详情，不 Push 到另一套普通详情界面。

### 壁纸

- 主 Tab 顺序为今日、年度册、壁纸、设置。
- 壁纸不放日期；语言跟随系统；无中文/英文和锁屏/主屏控件。
- 六模板顺序锁定：留白竖排、留白横排、上文下画、上画下文、左右对景、仅插画。
- 模板选择器占独立整行；窄屏允许横向滚动，保证触控尺寸。参考稿中六个缩略图有具体图文排布，不能仅用空卡框替代。
- 中央左右滑动同时换插画与配对语录，保留所选模板；仅插画模板隐藏语录但不改变内容包。
- 主按钮“导出高清壁纸”。最终根据设备屏幕像素尺寸渲染独立壁纸，不能保存低分辨率 UI 预览截图；用户经系统分享完成后续操作，不直接设置系统墙纸。

### 永久解锁

- 购买区优先：四行具体权益、当前本地化价格、一次买断说明、全宽朱红“永久解锁”按钮。
- 高保真中的“价格待定”仅占位；不硬编码金额、年份、内容数量或“原创手绘”营销词。
- 恢复购买、关闭、法律链接保持可达。小屏或大字号下权益滚动，购买区保持可达且不遮挡最后一行内容。
- 静态稿不是购买行为的实现或验证；StoreKit 接入属于后续业务实现范围。

## Widget 与多端

- 每种 Family 使用独立排版，共用同一个日期→内容包映射。Small/Medium 省略长篇名；Large/XL 保留小型出处。
- 导出的设计容器仅作参考，以 WidgetKit 提供的实际尺寸和可用区域排版，不能按型号硬编码。
- Small 背景与前景文字分区，插画焦点位于右上，不覆盖短句。Medium 左文右画，Large 上文下画，XL 左画右文。
- 圆形锁屏仅日期；矩形锁屏日期+极短语录；Inline 严格单行。锁屏预览深色底不属于需要实现的自定义底板。
- StandBy/透明/着色外观由系统环境决定；夜间降低装饰信息，不承诺实际效果等同本包静态图。
- iPad/Mac 宽屏稿展示侧栏、日期索引和已打开的图文阅读区域，详情呈现模式应与现有交互规范保持一致，不把辅助排版稿误作新业务流程。
- iPhone 横屏/窄窗口用自适应布局；Duo 等环境按实际可用空间处理，不根据名称推断某个 Family 必然可用。

## 图标与资源绑定

SF Symbols 名称：calendar、books.vertical、photo、gearshape、square.and.arrow.up、xmark、ellipsis、checkmark。

图标采用原生 symbol，不从设计稿导出 Apple 图标位图作为跨平台素材。选中态使用 accent，非选中态使用 secondary。除该组系统图标以外，所有文字用 B 字体。

只导入 Decor.xcassets、Theme.xcassets 与 fonts 中选定文件。sources、screens、boards、widgets、assets/mock-only 均不能作为整图资源直接接入 Release；字体许可证要随实际分发保留。
