# 本轮素材生成记录

工具：内置 imagegen。用途：三个独立位图素材；之后全部文字和高保真布局由 AppKit/CoreText 与真实字体合成。没有使用网页前端或 AI 生成字形作为正式字体。

## 概念占位画

输入：sources/reference-today.png，旧 AI 概念稿，不是设计师交付插画。

请求：保留树旁阅读青年、山水河村，移除日历 UI、文字、日期、铜环、纸边和阴影。生成横向水彩风景，人物在中右，树在右上，山村在左，保留淡墨与水彩边缘透明度及衣服/书页/云雾中的白色。输出真正 Alpha 背景。仅用于高保真占位，不作正式插画。

输出：sources/mock-reader-master.png → assets/mock-only/reader-landscape.png。

## 米白纸纹

请求：单张正方形米白书纸纹理，均匀照明，暖淡米色 #F7F0E3，极细纤维、低对比，无文字、折痕、污点、边框、阴影、渐变或物体，期望边缘均匀便于重复使用。

输出：sources/paper-master.png → assets/decor/paper-ivory 各倍率。实际未以无缝平铺为交付承诺，界面采用低透明度整片叠加。

## 铜环

请求：一个独立暖铜抛光长椭圆装订环，近正面三分之四视角，圆管金属、高光、宽高约 0.42，孔洞与外围真实透明，无纸张、文字、日期、手、额外环或地面。

输出：sources/copper-ring-master.png → 按 Alpha 边界修剪并导出 24×58 pt 的 1×/2×/3× 切图。

这三个素材的源文件与最终切图均保留在本包，不依赖生成工具缓存。装饰可供工程接入复核，mock-only 画面不能当作设计师原创或正式内容授权的替代。
