## 可实现的排版基线

| 部分 | 字体/字号 | 布局 |
|---|---|---|
| App 页标题 | 思源宋体 SemiBold 28 pt | 左侧内边距 24 pt |
| 今日卡片大日期 | Literata 94 pt | 右上，按实际字体行高预留 145 pt |
| 正面竖排语录 | 思源宋体 Regular 27 pt | 从右向左两列，按语义断行 |
| 详情标题/日期 | SemiBold 26 / Regular 14 pt | 固定 Header；底部分隔线 y=209 |
| 详情正文 | Regular 17 pt | 310 pt 文本宽，额外行距 7 pt |
| 年度册缩略页 | 大日期 Literata 48，语录 Regular 14 pt | 独立单页；日期间使用不同候选语录占位 |
| 壁纸操作 | SemiBold 22 pt | 六项独占整行；高清导出按钮 56 pt 高 |
| 付费墙权益/按钮 | Regular 18 / SemiBold 22 pt | 四行权益，价格与主按钮集中于同一购买区 |
| Widget 中文短句 | Regular 15–23 pt | Small/Large 按语义断行，不让“权。”孤立一行 |
| Widget 英文短句 | Literata 13–21 pt | 独立横排，自然单词换行；不把英文字母竖排 |

这是默认字号基线，不是生产代码里的固定尺寸承诺。大字号、小屏、安全区和系统容器需要自适应后再验收，不能直接缩放整张图片。

## 交互交接约束

- 今日页左滑下一天、右滑上一天；点击卡片打开背面。
- 详情 Header 保持固定，“语录详解”与日期不滚动；Header 下方全部正文进入同一个自然滚动区域，不只是末尾段落滚动。
- 图标尺寸不等于触控尺寸：详情关闭控件需至少 44×44 pt 命中区域，并在实现时检查互不重叠。
- 本轮长正文图只模拟视口裁切。后续原型要验证滚动、点击蒙层关闭、焦点恢复及减少动态效果，不能把静态图片当作交互完成。
- 壁纸仍无语言和锁屏/主屏选择，无日期；六种编排整行展示；窄屏可横向滚动，主按钮为“导出高清壁纸”。
- 永久解锁按钮首屏可达；价格待定仅设计占位。实际价格未加载时应提供加载/重试状态，不能让未知价格发起购买。

## 文本压力样本与测量

长句使用已有核验样本 SWM-004-002 的中英文，仅作为排版压力样本，不升级 candidate 状态或绑定正式日期。年度册里不同候选语录也仅用于测量，不生成正式年度池。详情解释为明确标注的编辑测试文字，不冒充历史释义。

本轮长句在 Small/Medium 预留文字区内不能完整放下，在 XL 压力样张的 402 pt 文字区内可放下。只证明这些样句与容器的测量结果，不代表所有 365 条都适配；生产规则仍是先使用已审定短版，再在缺短版时回退日期与插画，完整内容进 App 阅读。
