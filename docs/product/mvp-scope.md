# V1 产品范围与验收边界

更新日期：2026-10-29

## 1. 定义

由于用户明确要求 iPhone、iPhone Duo、iPad 和 Mac 都有完整体验，本项目不采用“只做一个手机 Demo”的传统 MVP。这里的 V1 指可正式发布、内容完整、跨平台基本体验成立的最小版本。

## 2. V1 必须包含

### 内容

- 365 套无固定日期的原创插画与中文摘编内容包，以及 1 套闰日专属内容；
- 每条均有来源片段、篇名、卷次和中文底本定位；
- 英文采用权威底本原句/片段，或基于权威片段的项目编辑译文；
- 原文、摘编、英文类型和项目解读分层存储；
- 全部内容离线可用。

### App

- 今日、年度册、每日详情、壁纸工坊、设置与来源说明；
- 中文、英文和双语显示；
- iPhone、iPhone Duo、iPad、Mac 自适应布局；
- Dynamic Type、VoiceOver、减少动态效果和高对比度基础支持；
- 稳定日期深链。
- 版本化的年度确定性洗牌，普通年年内 365 套不重复，闰日使用专属内容。

### Widget

- Small、Medium、Large；
- iPad/Mac Extra Large；
- Accessory Inline、Rectangular、Circular；
- StandBy、系统 tint/深色/透明模式验证；
- 点击打开对应日期。

### 数据与隐私

- 本地设置；
- 无账号、无服务端、无广告、无追踪；
- 不申请与核心体验无关的权限。

## 3. V1 可降级但架构预留

- 壁纸首发可只走系统分享，不申请照片写入；
- `systemExtraLargePortrait` 取决于最终 SDK、部署版本和真机验证；
- Mac 多窗口可先支持单主窗口，但数据与路由不得假设永远只有一个窗口；
- 农历极端日期和地区差异需产品确认显示规则。

## 4. V1 明确不做

- 账号、社交、评论、排行和用户投稿；
- CloudKit/iCloud 同步；
- 在线 AI 解读、自动翻译或人物对话；
- 广告、分析 SDK 和推送运营；
- Apple Watch、Apple Vision Pro 和 Android；
- 自由图片编辑器、任意字体商店或主题商城；
- 把扫描母版开放下载。

## 5. V1 验收标准

1. 365 条内容全部为 `approved`，没有候选内容进入 Release；
2. 随机抽查至少 10% 内容，可从设计稿文字回溯到全部来源片段与中英文底本；
3. iPhone、Duo 外屏/内屏/部分折叠、iPad 多窗口和 Mac 可调整窗口不出现主要内容跨折叠区、裁断或不可读；
4. 所有 Widget Family 使用各自构图并通过系统外观预览；
5. 午夜、时区变化、语言变化和深链打开日期均正确；
6. VoiceOver 阅读顺序、Dynamic Type 和减少动态效果可用；
7. 壁纸导出不包含超出授权范围的母版资源；
8. 离线首次启动即可阅读全部内容；
9. Release 不包含扫描底本、研究 PDF、密钥、临时文件或未授权资源。

## 6. 高保真设计前的交付顺序

1. 确认本 IA 与 V1 范围；
2. 设计 3 个视觉方向，均以同一套真实插画和语录为内容；
3. 选定方向后完成核心屏高保真：今日、年度册、详情、壁纸工坊、设置；
4. 为 iPhone 紧凑态、Duo 展开态、iPad 和 Mac 分别出关键屏；
5. 设计 Small、Medium、Large、Extra Large 和锁屏 Widget；
6. 归档真实字体高保真、设计参数与切图资源；用户已明确取消前端可交互原型；
7. 以归档稿建立原生 SwiftUI 工程并还原，在实际工程中验证导航、翻页、语言和壁纸流程。
