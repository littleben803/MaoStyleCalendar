# 产品差异化原则

## 1. 不做什么

- 不做“随机语录 + 通用背景图 + 订阅解锁字体”的模板化产品。
- 不复制现有《毛选日历》的名称、天气组合、AI 对话卖点或界面结构。
- 不依赖红底金字、红宝书和大字报作为唯一识别方式。
- 不用未经考据的“名言”数量制造内容丰富感。
- 不做人物模仿聊天、革命占卜或替用户下现实判断的功能。

## 2. 核心产品主张

暂定产品主张：

> 每天一幅原创手绘日历，阅读一句有出处、有上下文、有权威英译的中国现代思想文本。

产品不是简单的语录工具，而是可长期陈列和回看的双语数字日历作品。

## 3. 四个差异化支柱

### 原创日历艺术

- 每日独立手绘，而不是一套模板替换文字。
- 保留纸张、印刷和手作感，同时针对数字屏幕重新排版。
- 插画可以独立裁切和适配，不把完整纸页机械缩放到 Widget。

### 可验证的双语内容

- 每条中文、英文、篇名、卷次和页码都可追溯。
- App 内提供“查看出处”和必要历史语境。
- 明确区分权威英译、项目自译和版本差异。

### 为每个 Widget 尺寸重新创作

- Small：日期和一句最短摘录，强调一眼可读。
- Medium：插画局部、日期和精简双语内容。
- Large：接近完整纸质日历的阅读体验。
- Lock Screen：单色日期或极短句，不硬塞插画。
- StandBy：远距离可读的大日期和短句。

### 安静、离线、可信

- 无需登录，不追踪用户，不依赖在线生成。
- 每天一个经过编辑的页面，不做无限信息流。
- 主 App 是全年日历档案和出处阅读器，Widget 是每日入口。

## 4. MVP 必须证明的价值

在投入完整 365 张资源前，MVP 至少验证：

1. 原创插画在 Small、Medium、Large 三种尺寸仍能保持识别度。
2. 中英双语在 Medium 和 Large 中可读，不因信息过载损害日历感。
3. 用户愿意点击进入 App 查看出处或回看往日内容。
4. 海外目标用户理解这是历史文化与思想阅读产品，而不是缺乏语境的政治口号集合。
5. 品牌和 App Store 元数据能与已有同类产品清楚区分。
