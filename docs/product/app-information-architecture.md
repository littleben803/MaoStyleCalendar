# App 信息架构与关键交互

更新日期：2026-10-29

## 1. 产品结构结论

App 是一本可以每天使用、全年翻阅的数字艺术日历，不是 Widget 设置工具。四个一级入口为“今日、年度册、壁纸、设置”。

## 2. 一级信息架构

### 今日

- 展示当天完整插画、日期与设计稿摘编语录；
- 点击整张卡片翻转至当天详解；
- 左右切换前后日期，提供一键回到今天；
- Widget 深链默认打开对应日期，而不是固定打开今天。

### 年度册

- 月份索引：12 个月和每月封面/色彩提示；
- 缩略图总览：快速定位 365 张作品；
- 翻页阅读：保留纸质小册子的仪式感；
- 日期跳转：支持日历选择器和回到上次阅读位置；
- 不锁定未来日期，用户购买的是完整数字画册。

### 壁纸

- 在 365 套插画与语录配对内容间切换；
- 语录跟随系统语言，选择六种编排之一，支持仅插画；
- 根据当前设备尺寸导出，并由系统分享表完成保存或设置流程。

### 设置

- 默认语言：中文、英文、中英双语；
- 桌面小组件独立控制日期、干支和农历、语录的显示；
- 字号与减少动态效果；
- 内容来源、摘编规则、版权与插画作者信息；
- 数据说明与关于产品。

## 3. 每日详情的信息层级

1. `作品页`：插画、日期、设计稿摘编语录；
2. `出处`：篇名、卷次、文章日期、中文和英文版本页码；
3. `原文片段`：列出摘编所依据的一个或多个来源片段；
4. `历史背景`：解释文章当时的语境；
5. `今日解读`：项目编辑撰写的通俗说明；
6. `翻译说明`：指出英文是底本逐字原句、连续截句，还是基于权威片段的编辑译文。

用户首屏看到的是作品，不是考据表；但需要时可以完整追溯。

## 4. 壁纸工坊

从“壁纸”入口打开工坊。流程为：

1. 左右滑动切换插画与配对语录，语言跟随系统；
2. 从留白竖排、留白横排、上文下画、上画下文、左右对景、仅插画六种编排中选择；
3. 预览当前设备比例，页面不显示锁屏/主屏和语言选择；
4. 点击“导出高清壁纸”，使用系统分享面板导出，或在后续确认后增加照片写入能力。

不开放任意拖拽、任意字体和重度图片编辑，避免破坏设计师作品，也降低多端复杂度。

## 5. 导航适配

### iPhone 外屏与紧凑宽度

- 底部四标签：今日、年度册、壁纸、设置；
- 详情在今日卡片背面呈现；
- 翻页时保持单页沉浸阅读。

### iPhone Duo 内屏、iPad 与 Mac

- 使用 `NavigationSplitView`；
- 侧栏：今日、年度册、壁纸、设置；
- 内容列：月份和日期；
- 详情列：作品页与出处解读；
- 空间足够时同时显示“目录 + 作品”，不把手机 Tab Bar 生硬放大。

## 6. 核心交互规则

- 横向滑动用于前后日期，纵向滚动用于同一天的出处与解读；
- 翻页动效是视觉增强，必须支持“减少动态效果”；
- 所有 Widget 点击都通过稳定日期 ID 深链到对应页面；
- 中英文切换不改变当前日期、滚动位置；
- 窗口改变尺寸或 Duo 开合时保持当前选择，不能跳回首页。

## 7. 页面清单

| 页面 | iPhone | Duo 内屏/iPad | Mac |
|---|---|---|---|
| 今日作品 | 单页 | 作品 + 详情并列 | 可调宽详情区 |
| 年度册 | 月份/网格/详情逐层进入 | 两栏或三栏 | 三栏 + 键盘导航 |
| 每日详情 | 纵向详情页 | 作品与文字分栏 | 分栏，可独立滚动 |
| 壁纸工坊 | 全屏流程 | 预览与设置并列 | 大预览 + Inspector |
| 设置 | 最后一个 Tab | 侧栏详情 | 侧栏详情 |

## 8. 无障碍与本地化

- 文字保持可选取、可朗读，不将语录全部烘焙进插画；
- 支持 Dynamic Type、VoiceOver、提高对比度和减少动态效果；
- 竖排中文是视觉选项，辅助功能读取顺序仍按自然语序；
- 英文不能机械套用中文竖排版；
- 小尺寸下允许减少装饰，但不得裁掉核心人物或让文字不可读。
