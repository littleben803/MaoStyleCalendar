# 中英文语录来源与核验规范

## 1. 目标

确保产品中的每条中文语录均可回到正式中文底本，每条英文均可回到正式英文出版物，并能说明中英文之间是否为同一篇文章、同一语义片段。

“网络上广泛流传”“多个网站写法一致”不构成权威来源。

## 2. 首批内容范围

### 海外用词

- 《毛主席语录》的外文出版社 1966 年英译书名为 *Quotations from Chairman Mao Tse-tung*，海外常称 *Little Red Book*。两个说法都指向这本语录汇编。见 [摩根图书馆馆藏](https://www.themorgan.org/printed-books/225688)及[剑桥大学出版社研究](https://www.cambridge.org/core/books/abs/maos-little-red-book/single-spark/6ECACDD93D22760DC4622CCB47E29218)。
- 泛指产品所呈现的内容可写 `quotes from Mao Zedong’s Selected Works`。产品名称建议 `Mao Quotes: Daily Calendar`，主屏幕短名 `Mao Quotes`。引文来源按出版物原有拼写写作 *Selected Works of Mao Tse-tung*，卷次和页码逐条核验。见 [TheoryChina 外文版四卷书目](https://www.theorychina.org.cn/llzgyw/WorksofLeaders_984/)。

首批以《毛泽东选集》第一至第四卷为基础。2026-11-09 用户确认，365 套插画对应的语录如出自四卷之外，也可纳入有正式出版记录的原始底本，并另行核对英文版本。

扩大核验时逐篇登记：

- 《毛泽东选集》第五卷；
- 《毛泽东文集》；
- 诗词；
- 书信、题词、谈话和未收入四卷本的文稿；
- 仅见于《毛主席语录》汇编、二手文章或网络图片的句子仍须回溯到原篇。

新增底本单独记录版次、页码和版权审查。尚无对应正式英译的条目保留中文证据和英文检索状态。

## 3. 中文来源等级

### A 级：正式发布底本

1. 人民出版社《毛泽东选集》第一至第四卷，优先使用 1991 年第 2 版并记录实际印次。
2. 实体书或可信完整扫描件，用于页码、标点、段落和注释核验。

### B 级：官方检索入口

1. 共产党员网《毛泽东选集》第一至第四卷专题，可用于定位篇名和检索正文。
2. 中央党史和文献研究院、人民网理论频道等官方页面，可作为交叉证据。

B 级来源不能替代最终纸本页码核验。

### C 级：辅助检索

图书馆目录、学术论文、出版社书目和可靠索引，可用于确认版本与引用线索，但不能单独批准语录正文。

### 不可作为正式底本

- 百科、问答、博客、论坛、社交媒体；
- “名人名言”或语录聚合站；
- 没有版本信息的 PDF、OCR 文本和电子书；
- 图片中的引文；
- AI 生成或自动翻译结果。

## 4. 英文来源等级

### A 级：外文出版社正式英译本

`Selected Works of Mao Tse-tung`, Volumes I–IV, Foreign Languages Press, Peking。

每条英文必须记录卷次、篇名、版本/出版年、页码或稳定段落位置。英文标题和正文沿用底本拼写；产品品牌可以使用现代拼音 `Mao Zedong`，但引文书目信息保留底本的 `Mao Tse-tung`。

### B 级：官方书目信息

- 中央党史和文献研究院英文站 TheoryChina 的 Leaders' Works 页面，确认四卷由 Foreign Languages Press 出版。
- 大学或国家图书馆目录，用于核对出版年、卷次和中文底本对应关系。

### C 级：数字检索副本

由可信档案或研究项目转录、扫描的外文出版社版本，只能作为检索副本。批准前必须与 A 级版本的版权页、篇名、页码和正文相互核对。

数字副本必须记录文件 SHA-256。重新下载或替换扫描件后必须重新核对校验值，避免把不同重排版本的页码混在同一记录中。

### 自译处理

如果某条中文在外文出版社底本中没有可确认对应：

- 不得伪装成权威英译；
- 可以暂存为 `blocked_version_mismatch`；
- 如未来决定采用项目自译，必须明确标注 `Project translation`，并建立单独的翻译、母语编辑和法律审校流程。

## 5. 版本基线

当前建议基线：

| 语言 | 作品 | 建议底本 | 用途 |
|---|---|---|---|
| 中文 | 《毛泽东选集》1–4 卷 | 人民出版社，1991 年第 2 版，记录实际印次 | 中文原文、页码、段落 |
| 英文 | `Selected Works of Mao Tse-tung`, Vols. I–IV | Foreign Languages Press, Peking，各卷记录实际版本与出版年 | 英文原文、英文篇名、页码 |

图书馆目录显示，外文出版社第一至第三卷英译对应人民出版社 1960 年中文第二版，第四卷对应 1960 年中文第一版。因此，不能假设其与中文 1991 年版页码或措辞完全一致。

## 6. 单条语录必填字段

| 字段 | 说明 |
|---|---|
| `id` | 稳定 ID，例如 `SWM-001-001` |
| `content_pack_id` | 与对应插画组成内容包的稳定 ID，不绑定具体年份或日期 |
| `legacy_reference_date` | 原实体设计稿日期，仅供追溯，不参与运行时分配 |
| `zh_quote` | 按中文底本逐字录入 |
| `en_quote` | 按英文底本逐字录入 |
| `zh_work_title` | 中文篇名 |
| `en_work_title` | 英文篇名 |
| `volume` | 卷次 1–4 |
| `work_date` | 文章或讲话日期 |
| `zh_edition` | 中文出版社、版次、印次、年份 |
| `zh_page` | 中文页码；跨页需完整记录 |
| `en_edition` | 英文出版社、版本、年份 |
| `en_page` | 英文页码；跨页需完整记录 |
| `zh_context` | 中文完整段落或必要上下文，仅供审校 |
| `en_context` | 英文完整段落或必要上下文，仅供审校 |
| `source_links` | 在线检索入口，不替代版本信息 |
| `verification_status` | 采用 `AGENTS.md` 定义的状态 |
| `verified_by` | 核验人 |
| `verified_at` | 核验日期 |
| `notes` | 版本差异、截句理由和风险说明 |

结构化记录还应单独保存：

- `design_text_zh`：设计稿实际展示的文字，用于与底本原文比对；
- `excerpt_integrity`：完整句、连续截句或非连续改写；
- `blockers`：阻止升级状态的具体原因；
- `interpretation`：历史背景、通俗释义和翻译说明，必须与原文分栏存储。

## 7. 核验流程

1. 从设计稿或候选清单提取中文句子，状态设为 `candidate`。
2. 在官方目录中定位篇名，再回到中文纸本或可信扫描件逐字核对。
3. 保存完整上下文与每个来源片段，识别它是逐字原文、连续截句还是编辑性摘编，并检查组合后是否歪曲主语、条件、时间范围或否定关系。
4. 标记 `cn_verified`。
5. 在外文出版社对应卷和篇名中定位英文，不使用中文句子临时机翻搜索后直接录入。
6. 对照中英文完整段落，确认两者语义范围一致。
7. 记录两个版本及页码，标记 `bilingual_verified`；不一致则标记 `blocked_version_mismatch`。
8. 由内容编辑检查产品呈现、断句、标点和敏感语境，标记 `editorial_reviewed`。
9. 经项目负责人确认后标记 `approved`，才可生成正式资源。

设计稿展示文字可以是编辑性摘编，不要求必须连续，也不要求在日历页上显示省略号。它需要满足以下条件：

1. 核心词句能逐段回溯到明确篇目、章节和上下文；
2. 组合后的表达不反转、扩大或削弱原文核心意思；
3. 数据库保存设计稿文字、来源片段和完整上下文，详情页可解释摘编关系；
4. 英文优先采用外文出版社相应片段的既有措辞；跨句重组后的英文整体标记为项目编辑译文，不声称是底本中的连续原句；
5. 无法证明核心内容或组合后产生实质性误导时，才进入阻塞状态。

因此，`edited_or_noncontiguous_checked` 是内容类型和审校提醒，不是失败状态。

至少由两次独立检查覆盖：一次负责底本文字，一次负责中英对应和产品截句。

## 9. 发布门禁

- 构建脚本未来应拒绝包含非 `approved` 内容的 Release 资源。
- UI 可以在内部 Debug 模式展示候选内容，但必须有明显水印或状态标识。
- 正式截图、App Store 文案、宣传材料和 Widget 预览同样只能使用 `approved` 内容。
