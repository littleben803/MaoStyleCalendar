## 1. 使用原则

- 本表登记的是考据底本与检索入口，不代表拥有再分发整本扫描件的权利。
- 扫描件只用于内部逐字核验，不提交 Git、不打包进 App，也不作为用户可下载资源。
- 产品只保存经过核验的必要短引文、书目信息和项目自写解读。
- `PDF 页序` 是文件页序；`印刷页码` 是书页标注。正式记录优先使用印刷页码。

## 4. 已发现的版本风险

1. 外文出版社现代再版/重排 PDF 与 Peking 1965 扫描版的页序不同，不能混用页码。
2. 英文第一至第三卷和第四卷所对应的早期中文版本并不完全相同，不能假设其与中文 1991 年第 2 版逐页一致。
3. 中文官方网页偶尔引用 1991 年版页码，但只有明确给出篇名、卷次、出版社和页码时才可作为页码交叉证据。
4. 数字扫描件可能存在 OCR 错误；正式英文引文必须看页面影像逐字抄录，不能直接复制 OCR 文本。

## 5. 仍需取得

- 诗词等补充底本的逐篇页码、适用英文版本和每卷实际印次；
- 如果商业发行涉及较长引文、整页原文或大规模数据库式收录，需另做目标市场版权/合理使用法律审查。
